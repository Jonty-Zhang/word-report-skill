# 文体对照：自称、语气、结构

先判断文体，再动笔。判断依据依次是：用户原话（"结课论文""汇报稿""实验报告"）、模板标题、作业要求原文、素材形态。拿不准时按"课程报告"处理，并在交付说明里写明。

## 总表

| 文体 | 自称 | 人称与语气 | 默认结构 | 长度感 |
|---|---|---|---|---|
| 实验报告 | 尽量不自称；需要时用"本实验"。个别步骤描述可用"我" | 客观、过程导向、第三人称为主 | 目的 / 仪器 / 原理 / 步骤 / 数据与处理 / 误差分析 / 思考题 / 总结 | 数据和分析占大头 |
| 课程论文、小论文、结课论文 | "本文"；需要表达观点时"笔者" | 学术、论证式、克制 | 摘要 / 关键词 / 引言 / 主体章节 / 结论 / 参考文献 | 论证链完整 |
| 课程报告、期末报告（非论文体） | "本报告"或"本文" | 正式说明文 | 背景 / 内容 / 方法或过程 / 结果 / 总结 | 说明清楚即可 |
| 课程汇报稿、展示稿、发言稿 | "我"；小组用"我们" | 说给人听的：短句、口语化但不随意、可以有"接下来我讲…" | 开场 / 背景 / 做了什么 / 结果 / 收获 / 结束语 | 按讲的时间算，1 分钟约 200–250 字 |
| 小组项目报告 | "我们""本组""本项目""本系统" | 客观 + 团队视角 | 需求 / 设计 / 实现 / 测试 / 分工 / 总结 | 分工表要有 |
| 读书报告、学习心得、课程总结、反思 | "我"；也可"笔者"，全文只选一个 | 第一人称、有观点、有具体经历 | 概述 / 理解 / 思考与联系 / 收获 | 观点比复述多 |
| 文献综述 | "本文" | 综述体、比较式 | 引言 / 分类综述 / 比较与评价 / 展望 / 参考文献 | 有比较表 |
| 开题报告、结题报告 | "本课题""本研究""本项目" | 正式、计划性 | 背景与意义 / 目标 / 方案 / 进度 / 成果 / 预期 | 计划与成果对得上 |
| 调研报告、实践报告 | "本次调研""我们" | 纪实 + 分析 | 背景 / 方法 / 过程 / 发现 / 建议 | 有一手材料 |

## 通用规则

1. **全文只用一套自称。** 论文里前面"本文"后面"我"、心得里"笔者"和"我"来回换，都不行。
2. **不出现这些词**："用户""AI""助手""大模型""提示词""本 skill""生成"（指文本生成）。报告的作者是学生，读者是老师。
3. **不对读者说话**：不用"您""大家好"（汇报稿开场除外）、"请注意""如您所见""希望对您有帮助"。
4. **不在正文里复述作业要求**："本次作业要求我们…""按照课堂要求…""题目要求字数不少于…"。直接写做了什么。需要交代任务背景，用陈述句："本实验测量……""本文围绕……展开"。
5. **致谢与感谢**：只出现在论文、结题报告的"致谢"一节，或汇报稿的结束语，一两句即可。正文里不写"感谢老师的指导"。
6. **时态**：实验和项目用过去时或一般陈述（"测得""实现了"）；结论里不用"本文将…"这种未来时。
7. **英文夹杂**：术语首次出现给出中英文，后面统一；不夹 "anyway""ok""btw"。

## 各文体的补充说明

### 实验报告

- 步骤写成"连接电路，调节电压至 5 V"这种祈使/陈述句，不写"我先……然后我……"。
- 数据是原始数据，不四舍五入成好看的数。
- 误差分析具体到来源和量级，不写"存在一定误差"。
- 思考题按题作答，题干原样保留。

### 课程论文 / 小论文

- 摘要 200–300 字，含目的、方法、结果、结论，不写"本文首先……其次……"。
- 引言最后一段说明本文做什么、怎么组织，一段够了。
- 观点归到具体文献，不写"许多学者认为""研究表明"而不给出处。
- 结论回答引言提出的问题，给出具体结果，再写 2–4 句不足与后续工作。

### 汇报稿

- 一句话一个意思，句子短。
- 可以有过渡口语："先看背景""这部分我快速过一下"。
- 数字要念得出来："准确率从 82% 提到 91%"，不堆表格。
- 结束语一两句："以上是我们组的汇报，谢谢大家"可以有，正文里不再出现"谢谢"。
- 如果同时要 PPT 讲稿，按页分段，每段开头标页码。

### 小组项目报告

- 分工表要具体到人和模块。
- "我们"指全组；写个人负责部分时不切换成"我"，而写"XX 模块由 XX 负责实现"。
- 测试部分要有用例表：输入、预期、实际、是否通过。

### 读书报告 / 心得

- 复述原著不超过三分之一篇幅。
- 观点要落到具体章节、具体例子，不泛泛地"深受启发"。
- 允许写困惑和不同意见，这是这类文体的价值所在。

### 开题 / 结题

- 目标可检验；结题时逐条对照开题目标，完成的写结果，没完成的写原因和替代方案，一处说清。
